# تحدّي الكورة

موقع مستقل فيه 22 لعبة كرة قدم بالعربي. لا يعتمد على أي ملف من بقية مواقع المشروع.

## الملفات

| الملف | ما هو |
|---|---|
| `index.html` | الموقع كاملًا في صفحة واحدة، جاهز لأي استضافة |
| `data/kora.json` | بيانات اللاعبين والأندية والمباريات والقوائم |
| `src/` | الكود الأصلي (التصميم وكل لعبة في ملف) |
| `build.py` | يجمع `src/` في `index.html` و`app.html` |
| `tools/` | أدوات بناء البيانات من المصدر |

## مصدر البيانات

- **ويكي بيانات (Wikidata)**: الأسماء العربية، الجنسيات، المراكز، تواريخ الميلاد، ألوان الأندية، الملاعب، أبطال البطولات.
- **ويكيبيديا الإنجليزية**: جدول مسيرة كل لاعب (الأندية والسنوات والمباريات والأهداف) والتشكيلات الأساسية للمباريات التاريخية.

المصدران تديرهما مؤسسة ويكيميديا، ومجانيان، ويحدّثهما آلاف المحررين باستمرار.
الموقع يقرأ نسخة محفوظة من البيانات (`data/kora.json`)، فلا يتوقف حتى لو تعطّل المصدر.

## تحديث البيانات

```bash
pip install requests
bash kora/tools/run_all.sh
python3 kora/build.py
```

يستغرق البناء الكامل من الصفر حوالي ساعة إلى ساعتين، ثم يفحص `check_data.py` الملف تلقائيًا ويتوقف إن وجد خطأ.
