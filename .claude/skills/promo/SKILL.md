# تصميم ترويجي

1. لقطات حقيقية: Playwright بـ viewport 390×844 و deviceScaleFactor 3، الصفحة بـ `?local`، وعبّي `LOCAL` ببيانات (يفضّل نسخة من قاعدة البيانات الحقيقية عشان الصور والأسماء)، واخفِ شريط الوضع المحلي: `#bnLocal{display:none!important}`. اضبط `localStorage` `<prefix>tour=1` و `<prefix>crowdintro=1` عشان ما تطلع النوافذ.
2. التصميم: صفحة HTML بنفس الستايل:
   - خلفية `radial-gradient(120% 70% at 62% 4%,#14704A 0%,#0A3528 46%,#06231B 100%)`، وذهبي `#E6CC78`.
   - خط Tajawal/Cairo، وعنوان كبير أبيض + سطر ذهبي.
   - 3 جوالات (اللي بالنص أكبر)، وشارات (chips) تحت.
   - شعار: تمرين ساف `saff-white.png`، ونخبة السبت `emblem.png`.
   صوّرها بـ Playwright بالمقاس المطلوب و deviceScaleFactor 1.
3. شوف الصورة بنفسك (تداخل، كلام مقطوع، إيموجي نازل سطر) قبل ما ترسلها بـ SendUserFile.
4. المستخدم يحب: كلام قصير، بدون مبالغة، ويطلب تعديلات صغيرة كثيرة — خلّ السكربت سهل التعديل.
